# Excel排序工具使用说明

## 功能概述

根据一个Excel文件的某一列值顺序，对另一个Excel文件进行重新排序。

## 文件说明

| 文件 | 说明 |
|------|------|
| sort_main.py | 主程序（交互式） |
| user_sort.py | 用户脚本（手动选择文件） |
| quick_sort.py | 快速脚本（需预设路径） |
| 用户脚本.bat | 启动用户脚本 |
| 快速脚本.bat | 启动快速脚本 |
| excel_handler.py | Excel读写模块 |
| sort_logic.py | 排序逻辑核心 |

## 使用方式

### 方式一：用户脚本（推荐）

双击 `用户脚本.bat`，程序会交互式引导：

1. 输入参照Excel文件路径（仅一列作为排序依据）
2. 选择参照列序号
3. 输入目标Excel文件路径（需要排序的文件）
4. 选择匹配列序号
5. 选择是否模糊匹配
6. 选择是否保留未匹配行
7. 输入输出文件路径

### 方式二：快速脚本

1. 编辑 `quick_sort.py`，设置路径：
```python
REFERENCE_FILE = r"c:\path\to\reference.xlsx"
TARGET_FILE = r"c:\path\to\target.xlsx"
```

2. 双击 `快速脚本.bat`

### 方式三：主程序

双击 `运行排序工具.bat`，交互式操作。

## 排序逻辑

- 程序按照参照文件中值的顺序，重新排列目标文件中的行
- 默认保留未匹配的行（在最后）
- 支持精确匹配和模糊匹配

## 示例

**参照文件 (reference.xlsx)**
| 姓名 |
|------|
| 王五 |
| 李四 |
| 张三 |

**目标文件 (target.xlsx) - 排序前**
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25 | 北京 |
| 李四 | 30 | 上海 |
| 王五 | 35 | 广州 |

**排序后**
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 王五 | 35 | 广州 |
| 李四 | 30 | 上海 |
| 张三 | 25 | 北京 |
