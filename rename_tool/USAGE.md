# 文件重命名工具使用说明

## 功能概述

批量重命名文件夹中的文件，根据Excel模板指定的新名称。

## 文件说明

| 文件 | 说明 |
|------|------|
| file_rename.py | 主程序 |
| rename_logic.py | 重命名逻辑 |
| excel_handler.py | Excel读写模块 |
| file_operations.py | 文件操作模块 |
| user_script.py | 用户脚本 |
| quick_rename.py | 快速脚本 |
| 用户脚本.bat | 启动用户脚本 |
| 快速脚本.bat | 启动快速脚本 |

## 使用方式

### 方式一：用户脚本

双击 `用户脚本.bat`：

1. 修改脚本中的 folder_path 路径
2. 选择操作：
   - **1**: 生成重命名模板
   - **2**: 执行重命名
   - **3**: 试运行（预览）

### 方式二：快速脚本

1. 编辑 `quick_rename.py`：
```python
FOLDER_PATH = r"c:\path\to\folder"  # 目标文件夹
EXCEL_TEMPLATE_PATH = r""  # 模板路径（留空使用默认）
```

2. 双击 `快速脚本.bat`

3. 选择操作：
   - **1**: 生成模板
   - **2**: 试运行
   - **3**: 执行重命名

## 模板格式

生成的 `rename_template.xlsx` 包含以下列：

| 列名 | 说明 |
|------|------|
| 序号 | 文件顺序号 |
| 原文件名 | 原始文件名 |
| 新文件名 | 新的文件名（不包含扩展名） |

## 示例

**rename_template.xlsx**
| 序号 | 原文件名 | 新文件名 |
|------|----------|----------|
| 1 | 会议纪要.pdf | 2024年第一次会议纪要 |
| 2 | 报告.docx | 年度总结报告 |

## 输出结果

重命名完成后，会在目标文件夹生成 `rename_log.xlsx` 记录重命名历史。
